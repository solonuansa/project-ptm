# Arsip sebelum restrukturisasi

Salinan persis `main.tex` dan `main.pdf` sebelum perubahan susunan bab.
Referensi, tabel, gambar yang dipakai, dan berkas gaya ACL disertakan agar
versi ini tetap dapat dikompilasi secara mandiri. Hash tersimpan di `manifest.json`.

Dari direktori ini: `latexmk -pdf -interaction=nonstopmode -halt-on-error -outdir=build main.tex`.
